  The container
  
        Every Cellroom has its own machine, so you can build away from your computer.
        
  
        Each active Cellroom runs on an isolated machine with a shell, git and a headless browser. It clones, browses, builds and tests there. Your files, conversations and evidence stay saved when the machine shuts down.
